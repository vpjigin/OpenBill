# Security

## Supported versions

Security fixes are applied to the latest release tag on the default branch.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email the maintainers with:

- A description of the issue and impact
- Steps to reproduce (proof-of-concept if possible)
- Affected version or commit

We will acknowledge receipt within a few business days and work on a fix or mitigation.
If you need encrypted communication, say so in your initial message and we will provide a key.

## Scope

This project is offline-first shop billing software (desktop server + browser clients).
Reports about third-party services (Cloudflare, payment gateways) should go to those vendors unless our integration is clearly at fault.
